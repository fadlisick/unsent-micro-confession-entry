A two-part micro-confession for make.fun's "Unsent: The Micro-Confession Sprint": a To: line naming who the message was meant for, and the unsent line itself, written exactly as it was typed. The program writes that text to entry.txt, deterministically, with no input, no network and no randomness.

## Run it

```sh
python3 main.py
```
